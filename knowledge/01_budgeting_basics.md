# Budgeting Basics

Budgeting is a plan for your money. It helps you:
- Control spending
- Reduce financial stress
- Reach savings goals
- Prepare for emergencies

## Core components
- Income
- Fixed expenses (rent, bills)
- Variable expenses (food, transport)
- Savings
- Debt

## Simple budgeting loop
1) Track expenses
2) Categorize spending
3) Set limits
4) Review weekly
5) Adjust monthly

## When user asks
- “I don’t know where my money goes” → explain tracking + categories
- “I overspend” → suggest category caps + review habits
- “Help me manage money” → recommend starting with a simple budget
